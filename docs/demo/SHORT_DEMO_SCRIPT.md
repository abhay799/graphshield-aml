# GraphShield AML Short Demo Script (60–90 seconds)

This is a brief, presentation-friendly script for a tight recruiter or engineering review. Keep the narration short and avoid reading UI text line by line.

## 0:00–0:10 — Identity and problem

> GraphShield AML is a graph-native investigation-support system for AML review. It connects transaction alerts with network context, evidence, and policy support so a human reviewer can make a better decision.

## 0:10–0:25 — Mission Control

Show the AML Mission Control view.

> This is the triage layer: ranked alerts, case context, and source provenance. The queue is meant to help analysts prioritize, not automate enforcement.

## 0:25–0:45 — Graph Explorer

Show the graph explorer and a representative case.

> The graph view adds counterparty relationships, connected entities, and path context around the focal event. That is the missing piece in isolated transaction scoring.

## 0:45–1:00 — Evidence and policy context

Show path / evidence and policy retrieval.

> The workflow then brings in supporting evidence and policy references, helping the analyst understand the context before making a human decision.

## 1:00–1:20 — Review and boundaries

Show provenance or decision-support view.

> Human review remains required. The system is evidence-backed and read-only — it supports investigation, it does not autonomously file reports or take enforcement actions.

## 1:20–1:30 — Closing

> GraphShield demonstrates data engineering, graph intelligence, case investigation, explanation, RAG, governance, and an analyst interface in one human-controlled workflow.

## Recommended presentation order

1. Static portfolio hero or Streamlit landing page
2. AML Mission Control
3. Graph Explorer
4. Case Investigation / path evidence
5. Policy evidence or provenance view

Keep the short version focused on one case and one or two clear visual transitions.
