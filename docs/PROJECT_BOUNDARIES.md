# Project Boundaries

GraphShield AML is a research / portfolio decision-support platform.

## It does

- prioritize alerts
- expose point-in-time transaction and graph evidence
- explain risk signals
- retrieve policy context
- assist a human investigation
- record governance and reliability evidence

## It does not

- autonomously block accounts
- autonomously close cases
- file SAR/STR reports
- submit regulatory reports
- replace legal/compliance judgment
- automatically retrain/recalibrate/promote certified models
- use runtime ground-truth laundering labels as analyst evidence
- claim production SLO attainment from local/in-process tests

## Data

Use public or synthetic data only for portfolio/academic demonstrations.
